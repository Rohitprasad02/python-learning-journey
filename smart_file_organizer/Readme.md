# Smart File Organizer

A Python automation project that organizes files into folders based on their extensions.

## Features
- Scans files inside a source folder.
- Identifies file types using extensions.
- Creates category folders automatically.
- Moves files into their respective folders.
- Handles duplicate filenames using unique names.
- Generates an organization summary.
- Uses exception handling for file operations.

## Technologies
- Python
- pathlib
- shutil

## How to Run

1. Clone or download the project.
2. Create a `test_files` folder.
3. Add sample files.
4. Run:

```bash
python main.py
```
