# CSV Data Analyzer

A Python project that analyzes sales data stored in a CSV file.

## Features
- Calculates revenue for each product
- Calculates product-wise and total profit
- Shows category-wise revenue
- Finds the best-selling product by revenue
- Calculates average revenue
- Counts total items sold

## Technologies Used
- Python
- CSV module
- Dictionaries, loops, and functions

## How to Run
1. Make sure Python is installed.
2. Keep `main.py` and `sales.csv` in the same folder.
3. Open a terminal in the project folder.
4. Run:

   `python main.py`

## Project Files
- `main.py` — analysis logic
- `sales.csv` — sample sales data
